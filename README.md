# Cassette Lab | Releases

Download builds of [Cassette Lab](https://cassettelab.com), a desktop app for musicians to
organize and back up their DAW projects. This repo holds release builds only. The source is
private.

## Download

**[Download for macOS](https://github.com/BeatsNCode/cassette-lab-releases/releases/latest/download/Cassette-Lab-universal.dmg)**
(universal: Apple silicon and Intel)

This link always points at the latest release. Older versions and release notes are on the
[Releases](https://github.com/BeatsNCode/cassette-lab-releases/releases) page.

### Requirements

- macOS 12 Monterey or later
- A Cassette Lab account (create one in the app or at [cassettelab.com](https://cassettelab.com))

Windows is planned but not available yet.

## Install

1. Open `Cassette-Lab-universal.dmg`.
2. Drag **Cassette Lab** into **Applications**.
3. Launch it from Applications.

The app is signed with an Apple Developer ID and notarized by Apple, so it opens without a
Gatekeeper warning.

## Updates

Cassette Lab checks this repo for new releases and updates itself, so you don't need to
download each version by hand.

## Supported DAWs

- Logic Pro
- GarageBand
- Ableton Live
- FL Studio

## Release assets

| File | What it is |
|------|------------|
